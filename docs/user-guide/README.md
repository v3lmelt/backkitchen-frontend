## 主催与副主催

建议按以下顺序阅读：

1. [创建和管理社团](producer/circles.md)
2. [创建专辑并配置制作团队](producer/albums.md)
3. [设置同行评审规则](producer/workflow.md)

## 曲师与同行评审人

建议先完成[注册、邮箱验证与登录](getting-started.md)，并通过邀请码加入社团，然后按实际职责阅读：

1. [提交自己的曲目](composer/submission.md)
2. [进行同行评审](composer/peer-review.md)
3. [处理反馈、上传修订与确认母带](composer/revision.md)

曲师可以投稿自己的曲目，同时评审同一专辑中的其他曲目，但不能评审自己参与创作的曲目。

## 母带工程师

建议先完成[注册、邮箱验证与登录](getting-started.md)，通过邀请码加入社团，并确认自己已被指定为目标专辑的母带工程师，然后阅读：

- [母带沟通、交付、修改与确认](mastering.md)

社团中的母带工程师身份不会自动分配具体专辑任务。

## 关于工作流

正文以平台默认工作流为准。主催可以为专辑配置自定义工作流，因此实际阶段名称、负责人和可用操作可能不同。处理任务时，应以曲目页面显示的当前阶段和按钮为准。

自定义工作流应保留系统预置的终审步骤；可以调整其显示名称和规则，但不要删除后另建同类终审步骤替代，否则最终批准操作可能不可用。
