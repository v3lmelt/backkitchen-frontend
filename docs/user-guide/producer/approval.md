# 主催审批、拒绝与重新投稿

适用对象：主催、副主催  
适用阶段：主催审批、已拒绝

同行评审通过，或主催在接收审核中选择“跳过同行评审”后，曲目进入“主催审批”。主催需要判断当前源文件是否可以进入母带制作。

## 操作前确认

- 已经审听当前源文件版本。
- 已经查看同行评审结论和同行评审清单。
- 已经检查公开问题及其处理状态。
- 已经阅读曲师的修订说明。
- 已经确认当前版本满足送母带的基本要求。

## 检查评审和修订结果

1. 打开处于“主催审批”的曲目。
2. 确认当前播放的是最新源文件版本。
3. 查看同行评审提交的结论。
4. 检查仍处于“待处理”或“有异议”的问题。
5. 必要时打开历史版本比较修订前后的差异。
6. 阅读曲师填写的修订说明和问题处理说明。

问题被标记为“已解决”不代表主催必须接受结果。仍有疑问时，可以通过评论继续确认，或要求再次修订。

主催审批不是多人同行评审阶段，只支持公开问题，不会显示“仅内部”。旧页面或其他客户端尝试提交“仅内部”时，平台会拒绝请求且不会创建问题。

## 送「母带制作」

确认源文件可以交付后：

1. 点击“送「母带制作」”。
2. 确认流程推进。
3. 检查曲目状态是否变为“母带制作”。
4. 确认专辑母带工程师收到任务。

如果专辑尚未指定母带工程师，应先返回专辑设置完成分配。


## 再次要求源版本修订

当前源文件仍需修改时：

1. 创建问题或发表评论，记录具体修订要求。
2. 点击“打回”。
3. 确认曲目进入主催修订阶段。

“打回”操作没有单独填写原因的表单。应在点击前使用具体问题、时间标记或评论说明修改要求，不要只留下“继续修改”等无法判断完成标准的内容。

投稿曲师上传新版本后，曲目会返回“主催审批”，由主催再次检查。

## 退回同行评审

默认工作流允许主催将曲目退回“同行评审”。适合以下情况：

- 新版本改变较大，需要重新进行完整评审；
- 原评审意见未覆盖关键问题；
- 需要由其他评审人重新检查。

点击“打回到「同行评审」”并确认。退回后，应检查现有评审分配是否仍然有效，并告知评审人需要重点复查的内容。

## 拒绝方式

默认流程主要在“接收审核”阶段提供两种拒绝方式：

### 最终拒绝

曲目不再参与当前专辑，且不能由曲师通过普通操作重新提交。执行前应先下载需要保留的文件，不要依赖平台长期保留被拒绝曲目的音频。当前确认界面提示文件将在 1 天后删除；具体保留期限以平台管理员说明为准。

### 拒绝（可重新提交）

曲师可以上传新的源文件，开启新的制作周期，并重新进入流程第一阶段。

执行拒绝前，应通过评论或其他团队沟通说明原因。对于可能修正的问题，优先考虑允许重新提交。

## 曲师重新投稿后的处理

曲师点击“上传新源音频”并上传新文件后：

- 曲目的制作周期增加；
- 新文件成为当前源版本；
- 旧周期的问题、版本和工作流记录继续保留；
- 曲目返回当前工作流的第一阶段；
- 主催需要重新进行接收审核。

重新接收时，应确认原拒绝原因已经处理，并注意不要将旧周期问题误认为当前版本的新问题。

## 常见问题

### 看不到“送「母带制作」”

请确认：

- 当前阶段确实是“主催审批”；
- 当前用户具有专辑管理权限；
- 工作流中主催审批阶段存在通往母带阶段的通过路径。

### 曲师上传新版本后没有返回主催审批

实际返回阶段由专辑工作流决定。请查看曲目工作流进度，并检查自定义工作流中的修订回路设置。

### 仍有未解决问题，是否可以送「母带制作」

平台可能不会自动阻止所有未解决问题下的推进。主催应根据问题严重程度和团队结论自行判断，并在推进前确认关键问题已经处理。

### 已拒绝曲目没有“上传新源音频”

该曲目可能使用了“最终拒绝”，而不是“拒绝（可重新提交）”。最终拒绝不能通过普通流程重新投稿。
