# 平台与完整制作流程

适用对象：所有用户

Back Kitchen 用于管理同人音乐专辑中从曲目投稿、同行评审、源文件修订、母带制作到最终确认的完整流程。平台会记录曲目当前阶段、负责人、问题、评论、文件版本和操作历史。

## 默认制作流程

新建专辑默认使用以下流程：

```text
曲师提交曲目
  ↓
主催接收审核
  ├─ 送「同行评审」
  ├─ 跳过同行评审
  ├─ 最终拒绝
  └─ 拒绝（可重新提交）
  ↓
同行评审 ↔ 曲师修订
  ↓
主催审批 ↔ 曲师再次修订
  └─ 可退回同行评审
  ↓
母带制作 ↔ 源文件或分轨修订
  ↓
终审
  ↓
主催与投稿曲师分别批准
  ↓
已完成
```

![默认工作流配置](assets/producer-workflow-settings.png)

默认第一阶段在曲目页面显示为“接收审核”，在工作流编辑器的阶段类型中显示为“接收审批”；两者指同一阶段。本文描述曲目处理时使用“接收审核”，描述工作流配置项时使用“接收审批”。

## 各阶段由谁操作

| 阶段 | 主要操作人 | 主要工作 |
|---|---|---|
| 提交曲目 | 投稿曲师 | 上传音频并填写曲目信息 |
| 接收审核 | 主催、副主催 | 决定送「同行评审」、直接审核或拒绝 |
| 同行评审 | 被分配的评审人 | 审听、提出问题并提交评审结论 |
| 同行修订 | 投稿曲师 | 处理问题并上传新的源文件版本 |
| 主催审批 | 主催、副主催 | 检查评审和修订结果，决定是否送母带 |
| 主催要求修订 | 投稿曲师 | 根据主催意见再次修改源文件 |
| 母带制作 | 专辑母带工程师 | 沟通、审听并上传母带交付物 |
| 母带阶段修订 | 投稿曲师 | 修改源文件或提交外部分轨链接 |
| 终审 | 主催与投稿曲师 | 分别检查并批准当前母带 |
| 已完成 | 所有参与者 | 查看最终文件和完整制作记录 |

## 认识自己的职责

同一用户在不同社团、专辑和曲目中可能承担不同职责：

- 主催负责组织社团和管理专辑。
- 副主催可以协助管理所属社团及其专辑。
- 曲师可能是某首曲目的投稿者，也可能是其他曲目的同行评审人。
- 母带工程师（界面简称“母带师”）只有在被指定到某张专辑后，才能处理该专辑的母带任务。

曲师可以投稿自己的曲目，同时评审其他人的曲目，但不能评审自己参与创作的曲目。

## 查看当前需要处理的工作

登录后，可通过以下位置判断下一步操作：

1. 在仪表盘查看分配给自己的任务。
2. 打开通知中心查看新投稿、评审分配、修订请求和审批结果。
3. 进入曲目详情，查看工作流进度和当前阶段。
4. 只有当前负责人会看到对应的流程操作按钮。

按钮不可见通常表示当前阶段不由该用户处理，或用户尚未被分配相应职责。

## 自定义工作流

主催可以在专辑设置中调整工作流，例如：

- 改变评审分配方式；
- 调整所需评审人数；
- 允许主催跳过同行评审；
- 设置修订回路和额外退回目标；
- 要求母带上传后先由上传者确认。

因此，实际专辑的阶段显示名称、负责人或可用操作可能与默认流程不同。处理任务时，应以曲目页面显示的当前阶段和操作按钮为准。

自定义工作流时应保留系统预置的终审步骤；可以调整其显示名称和规则，但不要删除后再新建同类终审步骤替代，否则最终批准操作可能不可用。

## 数据保留概要

曲目完成后，非当前源版本的音频文件默认只继续保留 7 天；版本记录和关联问题可能继续显示。曲目或专辑归档后可在 14 天内恢复，超过期限后，归档对象及其关联记录和文件会被永久删除。需要长期保存时，应在完成或归档前及时下载。
